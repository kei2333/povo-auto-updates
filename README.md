# povo 自动填码修复版

此仓库仅发布安装包、版本元数据和更新说明。不包含用户优惠码、手机数据、测试截图或签名私钥。

[下载最新版](https://github.com/kei2333/povo-auto-updates/releases/latest)

软件每天自动检查并下载新版，或在主界面选择「检查更新 / 安装新版」。安装时仍需 Android 系统确认。

升级前检查包名、版本、文件大小、SHA-256 和与本机一致的签名；覆盖升级保留本机设置，并恢复到期自动兑换计划。

更新元数据：[update.json](https://github.com/kei2333/povo-auto-updates/releases/latest/download/update.json)

本项目为个人本机自动化工具，与 KDDI / povo 官方无隶属关系。
